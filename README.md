# Spring Boot Hello World (Gradle)

A minimal Spring Boot 4 project using Gradle with endpoints:

- `GET /` -> `OK`
- `GET /hello` -> `Hello, World!`

## Prerequisites

- Java 21+

## Run

```bash
./gradlew bootRun
```

Then open:

- <http://localhost:8080/>
- <http://localhost:8080/hello>

## Test

```bash
./gradlew test
```
